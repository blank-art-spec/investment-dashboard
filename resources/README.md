# 公共默认资源

`defaults/ah_pairs.json` 保存 15 组公开 A/H 股票代码配对，`defaults/etf_family.json` 保存 27 组 ETF/LOF 分类。
内容只包含公司或分类名称、公开证券代码、关键词和排除词，没有个人持仓、关注历史、密钥或 Cookie。

新源码副本首次加载共享层时，`dash_core/bootstrap.py` 将缺失的规则写入本机 `data/`。
已有文件始终优先，不自动覆盖。业务模块仍读取 `data/` 中的规则，原有匹配方式不变。

要更改仓库默认分类，在这里修改并手动验证；要调整本机分类，修改 `data/` 的副本。
新增默认规则也必须同步修改 `bootstrap.py` 的固定清单，不能扫描并复制整个用户数据目录。
