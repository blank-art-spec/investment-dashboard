# 手动运行验证清单

Python 服务以解释方式运行。本项目不要求预先编译；请由使用者手动启动并核对功能。
本次结构优化只进行了静态文件与路径检查，没有自动启动服务、发起抓取、调用模型或运行下面的脚本。

## 启动与停止

1. 环境不存在时先运行根目录 `安装依赖.bat`。检查 `.venv/Scripts/python.exe` 已建立。
2. 双击 `scripts/windows/run.bat`，确认出现服务监听提示，访问 `http://127.0.0.1:5001/`。
3. 确认首页可加载，浏览器没有静态资源 404，个股详情页能打开。
4. 手动关闭前台服务后，双击 `启动投资仪表盘.vbs`，确认后台启动与浏览器打开正常。
5. 双击 `停止服务.bat`，确认本项目服务停止；再次启动应仍正常。
6. 若仍使用旧入口，可手动双击 `investment-dashboard/run.bat`。此入口应运行同一套应用及数据。

若使用自定义端口，启动前设置 `DASH_PORT`，并在相同环境下调用停止入口。
不要同时运行前台和后台两套服务来验证数据写入。

## 原功能检查

| 项目 | 手动确认 |
| --- | --- |
| 数据与账户 | 原持仓、现金、交易、候选池、账户选择和历史记录可见；切换账户后数据仍隔离。 |
| 首页 | 行情、人民币核算、盈亏、风险、建议、连续盈利天数与投资行为体检可显示。 |
| 投资框架 | 地图、分层、日记分类和排序、宏观报警、红利低波评分可打开。 |
| 宏观 | 估值、利率汇率、商品、航运、大 V 观点与黄金周期面板可显示。 |
| 机会 | 雪球列表与历史观点、套利、超跌、港股打新、月度金股及截止日提醒可打开。 |
| 个股 | 详情、K 线、基本面、财务预测、舆情与事件可显示。 |
| 本地研报 | 迁移后的原报告仍出现在对应个股页；自定义 DASH_REPORT_DIR 时按配置查找。 |
| 量化复盘 | 策略、已有快照、回测、收益归因与真实净值可读取。 |
| 设置 | 已有接口配置仍可读取，普通偏好与密钥存储继续分离。 |
| Edge 抓取 | 由用户手动发起并核对专用窗口；本次迁移前目录清单中未发现已存在的浏览器 profile。 |

验证写入、交易撤销或 AI 更新时，使用测试账户或数据备份；这些操作按原业务规则修改数据。
模型功能需要有效接口配置，手动验证会发出真实请求；外部源暂时不可达应结合日志区分路径错误与上游问题。

## 选择相关验证脚本

`tests/` 保留原有 34 个 `verify_*.py`。部分脚本读取历史数据或创建临时输出，先看顶部说明。
这些脚本是独立可执行程序，本次没有改为自动收集的测试套件。

例如，在项目根目录打开 PowerShell，由你选择执行：

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:PYTHONNOUSERSITE = '1'
$env:PYTHONUTF8 = '1'
& .\.venv\Scripts\python.exe -B .\tests\verify_xq_finance_fallback.py
& .\.venv\Scripts\python.exe -B .\tests\verify_hk_ipo.py
& .\.venv\Scripts\python.exe -B .\tests\verify_gamble.py
```

上面三个脚本的顶部说明声明不调用网络或模型，通过替换外部依赖验证相应逻辑。
不要将示例命令改成不加筛选地执行所有验证脚本；如需完整回归，应先逐个确认数据前提和副作用。
脚本历史注释中出现旧电脑 Python 路径时，以本项目 `.venv` 解释器为准。
